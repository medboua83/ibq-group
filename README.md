# IBQ GROUP

Site vitrine en français : ingénierie et intégration audiovisuelle.

## Développement

npm ci
npm run dev

## Publication

Le workflow GitHub Actions publie le contenu de dist/client sur GitHub Pages à chaque mise à jour de main.
Activer Settings > Pages > Source > GitHub Actions.

Les photographies sont des illustrations générées, et ne représentent pas des références de projets réalisés. Le formulaire prépare un email dans la messagerie du visiteur.
